---
title: "Media Query Debugger"
---

This component shows the name of the currently active media query defined in the **[Media Query Setup](/docs/library/prefabs/media-query/components/media-query-setup)** component.

## Inputs

| Data                                                | Description                                                                          |
| --------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `Debugger Position` | Wether the debugger should render **inline** or be **fixed** in the top right corner |
