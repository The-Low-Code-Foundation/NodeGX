# Pie Chart Example

## Basic

```js
Outputs.Data = {
    labels: [
        'Red',
        'Yellow',
        'Blue'
    ],
    datasets: [
        {
            data: [10, 20, 30],
            backgroundColor: [
                '#FF5382',
                '#FFCC34',
                '#00A3F1'
            ],
        }
    ]
}
```
