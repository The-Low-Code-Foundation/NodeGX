# Turf.js API

Returns the Turf.js API object, allowing to use other Turf.js functions that doesn't have nodes yet.

## Outputs

| Data                                   | Description                                                        |
| -------------------------------------- | ------------------------------------------------------------------ |
| `Turf` | The Turf.js object, making it possible to call any Turf.js method. |
