---
title: "Geospatial Area"
---

Takes an array of coordinates and returns their area in different formats.

## Inputs

| Data                                          | Description     |
| --------------------------------------------- | --------------- |
| `Coordinates` | GeoJSON feature |

## Outputs

| Data                                              | Description |
| ------------------------------------------------- | ----------- |
| `Square Meters`   |             |
| `Square Hectares` |             |
| `Square Km`       |             |
| `Acres`           |             |

| Signal                                      | Description                          |
| ------------------------------------------- | ------------------------------------ |
| `Changed` | Occurs when the outputs are updated. |
