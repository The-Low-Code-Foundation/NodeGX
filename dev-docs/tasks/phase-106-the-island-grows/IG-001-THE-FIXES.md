## 1. The person sentence

> **A child presses One step through an Olive block and the owl stops thinking when she has answered; a
> win with the shortest program is a plain "Perfect!"; free play never says "not quite yet"; the running
> block is a ring anyone can see; and what Olive said is on the screen.**

## 2. What it is

Ten defects in the generator sources (`packages/noodl-mcp/tests/cg002Scripts.ts`, `cg003Components.ts`,
`cg003Scripts.ts`, `cg005Olive.ts`, `cg007Look.ts`) and the kit (`library/modules/garden-kit/src/kit.js`),
regenerated into `templates/bot-garden` and driven. Nothing here changes the product's shape.

| # | Defect (README §1 has the reading) | The fix |
|---|---|---|
| D1 | "Olive is thinking" never clears in One step; Start over / Teach leave it; a Step while parked sends a duplicate ask | in step mode `answered` clears `waiting` and advances `pc` without a tick; `stop` resets `waiting`; a Step while parked is a no-op with the tag still on |
| D2 | `gardenRun` leaks across requests | Start world and Start over reset the run (bumps, puddles, `ran`) before Choose hint can read it |

## 3. Acceptance criteria

1. **D1:** a page drive places `ask Olive · a poem` with the stub Olive, presses One step three times: the
   tag is on after press 2, **off** after the stub answers with no further press, and exactly one ask was
   sent (the stub counts). Start over while parked: tag off within one tick.
2. **D2:** drive request A to a bump, open request B, press "Done teaching": the hint is `hintStart`/`hintEmpty`,
   never `hintBump`.
3. **D3:** on path-stones, `repeat 4 × (put, fwd)` wins with `hintPerfect`; nine single blocks win with
   `hintDone`; the engine gate asserts both in EN and FR.
4. **D4:** free play, a clean run of three blocks: `hintFree`; a run that bumps: `hintBump`.
5. **D5:** contrast measured live (the P105 `cg007Look` contrast tool) on both backgrounds ≥ 3:1; the drop-line
   is unchanged in colour.
6. **D6:** the stub answers "Tulla the tulip"; the bubble shows that text on the robot in the `olive` style;
   `say` shows its line in the `plain` style.
7. **D7:** the picker lists `Olive says yes`; a program `ask Olive is-it-a → if Olive says yes → water`
   waters when the stub says yes and does not when it says no (the stub takes a scripted answer).
8. **D8:** no `plAsk` in the generated template; editing a block changes the hint within one step without a
   press.
9. **D9:** the stones request renders no `.gd-label` at all; the stone and the post box are `svg` elements
   with the kit's class names; a screenshot is looked at.
10. **D10:** the stones request's pad shows `fwd left right put` and not `water`; tulips' shows `water`.
11. Garden specs, the page drive at 1368×912 and 390×844 in EN and FR, the Olive page drive and the shell's
    tests all green; the template regenerated byte-identical by `npm run template:garden`; 0 console errors.

## 4. How to build it

In the order D2, D1, D3, D4 (engine and Runner), then D5, D9 (kit), then D6, D7, D8, D10 (page glue). Each fix
gets its gate assertion first, red, then green; the drive clauses above are added to the P105 drive wrappers
in `../phase-105-the-coding-garden/drives/`. Regenerate once per group, not per fix.

## 5. Gates

`packages/noodl-mcp` garden specs (cg002 engine, cg003 template, cg005 Olive); the kit gate on the built file
in a bare `vm`; the page drive on the deployed output with the stub Olive; the shell's `npm test`. The exit
status is the gate, never the run list (`a-run-list-is-not-a-log`).

## 6. Traps

The Runner's `rnLoop` condition (`playing`) is the whole D1 defect; adding a second branch for `paused` must
not tick a primitive (the answer only advances `pc`). `MANY_BLOCKS` stays a constant; never bump the literal
to make a count gate pass. The kit's built file must still end with `src/kit.js` verbatim and contain no
`url(`/`fetch(` (CG-001 AC10): the new sprites are inline SVG like the rest. A voiced hint must stay the hint
(P105 `unfaithful` check): `hintPerfect` joins the voiceable list in `olive-templates.json` or is not voiced.
