## Facts measured in session 16 that are not in a task file

  reopen the project before reading. A launcher card with a thumbnail puts its title below the fold — scroll it into
  view before `cdp click`.
- In a drive, `__nodeGraphEditor.findNodeWithId(id)` is the canvas's node VIEW; the model is `.model`
  (`.model.setParameter(name, value, {undo:true})`).
- The viewer build honours `OUT_PATH` (`webpack-configs/constants.js`), and `nodegx deploy` resolves its runtime
  relative to its own `noodl-preview/dist` — so a worktree with REAL copies of `src/external` and of the
  `noodl-preview`/`nodegx-export` dist deploys and renders with its own bundle and never touches the shared one.

  a sheet's owner by asking each `<style>`/`<link>` for its `.sheet`.

  whatever Model Request does.
- A Function in a cloud function runs on input change by default: wired from Request params AND `receive`, it can run
  before the request's values arrive. Prefab authors set every `runOnChange-in-*` to false (SendGrid does).
