Trying ideas

Build with your AI coder, on parts you can change

Set up a folder for NodeGX before your AI coder starts. Then say what you want to make. It plans the app with you, builds it from NodeGX parts, and leaves you a project you can open and change.

Before you start

You need Node.js and one AI coder

Node.js runs the setup commands. If you don’t have it, install it from nodejs.org. Then pick the AI coder you already use.

  1. Set up a folder. In a terminal, run: 
    npm create nodegx my-apps
  2. Open Claude Code in it. 
    cd my-apps
claude
    When Claude Code asks whether to use the nodegx server, say yes.
  3. Say what you want to make. A landing page for your band, a habit tracker, a quiz for your class. Claude asks a few questions first, then writes a brief and a plan into the project and builds it.
  1. Set up a folder. In a terminal, run: 
    npm create nodegx-cline my-apps
    This also adds NodeGX to Cline’s list of servers.
  2. Start Cline in it. 
    cd my-apps
cline
  3. Say what you want to make. Cline plans the app with you, then builds it.

  1. Set up a folder. In a terminal, run: 
    npm create nodegx-vibe my-apps
    The folder is set up for Mistral’s Large 4 model.
  2. Start Vibe in it. 
    cd my-apps
vibe --legacy-harness
  3. Say what you want to make. Vibe plans the app with you, then builds it.

Being finished. In Claude Desktop, NodeGX Studio will open inside the conversation while Claude builds, with a Hold button to stop it. The install will be one double-click. Join the mailing list to hear when it’s out.

Once it’s built

See it, change it, keep going

See it

Run it in your browser

Your AI coder tells you the app’s folder name. Then run:

npx @nodegx/preview my-app --open

The page reloads each time the app changes.

Change it

Open it in an editor

Every part lists its settings. Open the project in NodeGX Studio or the NodeGX editor and change it by hand. Or ask your AI coder to build you an editor of your own.

Take it with you

Leave with React source

See first what will come across, then write the app as React. This needs Node.js 22 or later.

npx @nodegx/export export --dry-run my-app

Code export is in alpha.

Games

Games keep their world in code

In the games we’ve built, the 3D world is plain code and the menus beside it are NodeGX. That keeps the hard part small for your AI coder. The menus stay easy to change. A kit with what we’ve learnt from those games is next.
