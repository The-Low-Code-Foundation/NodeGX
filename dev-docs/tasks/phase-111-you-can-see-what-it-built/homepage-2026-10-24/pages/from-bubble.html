Coming from Bubble

Bring your Bubble app into NodeGX Studio

Studio works the way a Bubble builder expects: pages, elements and workflows. It imports your app’s front end and its back end. The app then runs on your own machine. Claude Code can carry on building it with you.

What comes across

Most of your app, and a report on the rest

Comes across

The app you built

  • Pages, elements and styles
  • Workflows and custom states
  • Data types and option sets
  • Privacy rules
  • Backend workflows, which become cloud functions
  • API Connector calls, without their keys
Needs you

What you’ll redo or check

  • Plugins, which arrive as labelled placeholders
  • HTML, video, map, slider, date, file and picture inputs, also as placeholders
  • API keys and passwords, which never come across
  • Your data rows, which are a separate step

Every placeholder is listed in an import report saved beside the project.

The steps

From Bubble to Studio

  1. Get Studio. The download is coming soon.
    Coming soon notify me
    Can’t wait? Run it from its source

    You need Node.js 22. In a terminal, run:

    git clone https://github.com/The-Low-Code-Foundation/nodegx-studio
cd nodegx-studio
npm install
npm start
  2. Get your app out of Bubble. On the Growth plan or above, go to Settings, then General, then Export application. On another plan, you can save each page’s files from Chrome’s developer tools instead. The import guide shows how.
  3. Import it. On Studio’s welcome screen, choose Import an app. Pick your export file or your folder of page files, then an empty folder for the new project. A large app takes about a minute.
  4. Read the import report. It sits beside the project and lists every placeholder and anything that needs a decision from you.
  5. Bring your data across. Export your data types as CSV from Bubble’s Data tab. Moving the rows in is a separate command for now, described in the import guide. Studio’s Data tab then offers to check and load them.
  6. Keep building with Claude. Studio has a Connect Claude Code button. Ask Claude to rebuild a plugin, wire a page or tidy a workflow, and watch it happen in Studio.

Keep the export on your computer. Some of these files contain your app’s API keys.

Then

Publish your app, or keep it on your machine

Studio publishes to a folder you can host anywhere, with its cloud functions. Publishing to a server of your own is being finished. You can also run it on your own machine for as long as you like.
