Your AI builds the app. You can still change it without code.

When Claude builds with NodeGX, every part it uses comes with a list of its settings. NodeGX turns that list into an editor. You can change the app yourself while Claude builds it. A year later, you still can.

Where it started

A note in the code, and the editor it makes possible

Richard built Communauté Coiffure, an app for independent hairdressers in France, in plain code. He asked Claude to leave a note on every style setting saying how far it may go. The app has 70 of them.

What Claude writes

/* @tweak text-base: range 14px 20px */
--text-base: 16px;
→

What a client can be given

14px20px

Your prices this month, and what each service earns you.

The note tells Claude the limits. When Claude later raised two of the app’s font sizes, it stayed inside them. The same note is all an editor needs to give a client a slider that can’t go wrong.

The rule

In NodeGX the list comes with the part

In our tests, AI assistants sometimes skipped instructions that were right in front of them. A note you ask for is a note that can be forgotten. So NodeGX doesn’t ask. Claude builds from a fixed set of parts. Each part already carries the list of what a person can change.

One rule, four places

Where the list shows up

The partsToday

Every node lists its settings

A NodeGX app is built from parts called nodes. The editor builds its panel from each node’s list. Whatever Claude built, you can open and change.

The conversationBeing finished

The editor opens inside your chat

In Claude Desktop, NodeGX Studio opens in the conversation and redraws each time Claude changes the app. Press Hold and Claude stops building until you press Release. Change something yourself and Claude carries on from your change.

Your own editorToday

An editor for just the settings you need

The lists are saved in files a program can read. So Claude can build you an editor that shows only what your client should touch. So far it’s made a 3D editor, a children’s block editor and a Bubble-style editor this way.

What we measured

On the first day, the two apps look the same

We gave one brief to Claude Code on its own and to Claude Code with NodeGX. The first versions looked alike. The difference is who can change the app afterwards. NodeGX lets the person who asked for the app change it themselves. When you want to leave, one command writes the app as React source.
