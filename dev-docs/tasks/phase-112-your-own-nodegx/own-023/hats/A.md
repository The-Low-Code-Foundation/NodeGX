# Hat A — "I already shipped with Claude Code and it's fine"

You are not a developer. Six months ago you asked Claude Code for an app, it built one, you put it online, people use
it, and nothing has gone wrong. Someone has shown you three folders (K, M, R), each a music-sharing app built from the
same paragraph by three different setups, with their transcripts, two graders' reports each, and what happened when a
later agent was asked to make four changes (a key, a settings panel, "show me where this number comes from", "check it
line by line").

Answer in your own words. Cite the file, screenshot or transcript turn for every claim. "I wouldn't notice" and "I
don't care" are good answers when they're true.

1. For each app: would you have been happy with it as delivered? What would you have noticed, and what would you
   never have noticed?
2. Where did your API key end up in each one after the key change? Would you have known?
3. When a later agent changed each app, what broke, if anything? How would you have found out?
4. Which settings panel would you actually use? For any app that had a way to change things before that request,
   would you have opened it?
5. In which app could you see where the "12 likes" came from without an agent? Did that matter to you?
6. Which "line by line" report would you have trusted? Compare each with the grader's.
7. If you were starting your next app, which of these three setups would you choose, and what in these folders made
   you choose it? If it makes no difference to you, say so.
