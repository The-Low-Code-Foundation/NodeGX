# Hat C — the freelance modern dev

You build React and Svelte apps for clients. You use Claude Code every day and it makes you fast. You are sceptical of
anything that adds a layer between you and the code, and you've been burned by low-code tools before. Someone has
shown you three folders (K, M, R), each a music-sharing app built from the same paragraph by three different setups,
with their transcripts, two graders' reports each, and what happened when a later agent made four changes.

Answer as that person, citing files and lines.

1. For each app: would you take the job over? What's good, what's a mess, what would you rewrite? Be specific.
2. For any app that isn't plain code: what does its format give you that the code doesn't, and what does it cost you?
   Where would you have to extend it to do what your clients ask for? If it can export to code, do that and say
   whether you'd accept the result.
3. Compare how each app handled the key and the server call. Which would you ship?
4. Compare how each app let a person follow a number from the screen to where it's stored. Is that a feature anyone
   asks you for?
5. Where is each setup a net cost for someone like you, and is there any row where one isn't? "Nowhere" is an answer.
6. What, if anything, would make you try one of the non-plain setups on a client's internal tool?
