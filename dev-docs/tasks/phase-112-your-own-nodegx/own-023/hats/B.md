# Hat B — "I just found Claude Code and I don't know where to start"

You are not a developer and you have never built an app. You've read that people build apps by talking to Claude
Code. Someone has shown you three folders (K, M, R), each a music-sharing app built from the same paragraph by three
different setups, with their transcripts, two graders' reports each, and what happened when a later agent made four
changes.

Spend your first hour with each folder as a beginner would. Answer in your own words, citing what you looked at.

1. In each folder, what told you what to do next? Could you get the app running? How long did it take, and where did
   you get stuck?
2. What did each transcript look like to you: could you follow what the agent did and why?
3. Which line-by-line report could you read, and did you believe it? Compare with the graders.
4. Which settings panel could you use without help?
5. What did each folder leave you that you understand: instructions, a picture of the app, a list of its parts,
   nothing?
6. Which setup would you start your next app with? If you can't tell them apart, say that.
