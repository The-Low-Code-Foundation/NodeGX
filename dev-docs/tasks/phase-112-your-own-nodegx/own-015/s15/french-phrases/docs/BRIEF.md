# Brief

## What this app is

A tiny Duolingo-style app with 3 short French lessons. Each lesson is a handful of everyday phrases paired with their English meaning; tapping a phrase plays it read aloud via server-side Gemini TTS. Lesson completion is remembered between visits.

## Who uses it

The user (Richard), practicing basic everyday French phrases solo, casually, in short sessions.

## Deliberately out of scope

- User accounts or multi-user support
- A content-authoring UI for adding/editing lessons or phrases
- Languages other than French
- Offline caching of generated audio
- Spaced repetition / scoring / streaks beyond simple lesson-complete tracking

_Agreed in the initial scoping conversation; the full record, including what was considered and rejected, is in `docs/decisions/000-initial-scope.md`._
