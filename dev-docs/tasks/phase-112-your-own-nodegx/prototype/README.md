# Orbit — the prototype this phase was scoped from

A focus timer (Pomodoro) built as a NodeGX graph, running in a browser page on `@nodegx/node-spec` with no editor and
no runtime. The page is also a small editor: the NodeGX canvas look, three stages (Graph, Lift, Orbit), add a node
from a picker, wire by dragging, set properties, delete, and three missions that a fresh copy of your graph checks on
the specs. Built by Claude Code in one conversation on 2026-10-02, five versions between 21:33 and 23:08, while Richard
watched and steered. Published while it was being built as a claude.ai artifact (`TsE5boknvv5UoLhvtCUUX5`).

It is evidence, not a product. [The phase README](../README.md) §1 says what it proves and what it does not. A second
prototype, built the day after and better at explaining what a NodeGX app is, sits beside it in
[`../prototype-under-the-lid/`](../prototype-under-the-lid/README.md); [NEEDS.md](../NEEDS.md) measures both.

## Build and open

```sh
./build.sh            # writes dist/orbit.html (about 510 KB: the page plus every spec, inlined)
open dist/orbit.html  # needs WebGL; Three.js 0.170.0 loads from cdnjs
```

Two links do things by themselves:

- `dist/orbit.html#selftest` runs the three mission checks on the graph as it starts. **Every one must say "Not
  yet"**: that is the control that makes a pass mean something.
- `dist/orbit.html#demo` builds all three missions step by step, checks them (3 / 3), then lifts and orbits the result.

Measured on 2026-10-02 at `3bb2e084e` in headless Chrome: `#selftest` 0 / 3 with the three expected reasons,
`#demo` 3 / 3, no script errors.
Re-measured on 2026-10-03 after OWN-002 (built from the package's browser entry, no alias, define or stub): the same.

## What is in it

| file | what |
|---|---|
| `page.html` | the page: canvas (Three.js), panels, editing, missions. `/*NGX*/` is where the build inlines the bundle. |
| `src/graphrun.ts` | the graph runner: about 140 lines over the spec interpreter. **Wave-at-a-time, never graded** against the 76 graph scenarios; CONTRACT C7 (lockstep) is known to differ. One `World` per node, so nodes that share a store cannot run. OWN-003 replaces it. |
| `src/app.ts` | the timer's 18 spec nodes and 24 wires, in the prototype's own shape (not v2 files). The 8 visual nodes and their 11 wires are declared in `page.html`, because no visual node has a spec. |
| `src/entry.ts` | what the page gets from the bundle: `create`, `createFrom` (a copy for a check), `describe` (a node's ports, types and descriptions from its spec), the picker list. |
| `src/picker.json` | generated by `tools/genpicker.ts`: specced nodes whose world needs only clock, random or timezone (36 at scoping). |
| `tools/rough-census.ts` | the quick count behind README §1 reading 6. **Retired**: it walked a nested `nodes` field v2 nodes do not have (every v2 `nodes` array is flat). `scripts/own/census.js` replaced it on 2026-10-03 and reproduced its numbers to within the two `Page` nodes and one `CSS Definition` it mis-bucketed. |

## The four things it had to invent, which is the phase

1. **A graph runner.** The spec package runs one node; wiring is left to a target.
2. **The project.** An invented graph, not a v2 project: the format lives inside the editor's source.
3. **The screen.** Drawn by the page from the values the visual nodes' wires carry, because 0 of 19 visual nodes has
   a spec.
4. **The look.** Copied by reading `CanvasTheme.ts`, `NodeGraphEditorNode.ts` and `structureLane.ts`: a third copy
   of the canvas palette, which is exactly what memory says drifts.

## `real/` — Orbit as a real project (OWN-004 s4, 2026-10-10)

The same timer as v2 files (`real/orbit/`), run by NodeGX's own runtime through `@noodl/preview` in the page, with
its graph drawn in 3D around the real app or beside it in a flat window (one switch; Richard ruled *keep both*, R7).
Nothing in it draws the screen: the app is the app. Its graph differs from `src/app.ts` in one place, on purpose:
*Phase over* is evaluated on each tick, because the real engine showed the original wiring bounces a Skip back
(OWN-004 §6.2); this page's own runner never did.

```sh
real/build.sh                       # bundles @nodegx/canvas-look for the page (look.js, gitignored)
node real/serve.mjs 47812           # then open http://127.0.0.1:47812/orbit.html  (#window starts flat)
node real/check.mjs                 # the gate: both poses, 37 / 37 wires live, real presses, a full cycle
```

Needs the deploy runtime (`npm run build:editor:_viewer`) and the preview bundle (`npm --prefix
packages/noodl-preview run build`). `app.html` is the smallest host; `library.html` shows the runtime's ports for any
node type. When `orbit.html` gains this page's editing and missions (OWN-004 §6.3), `page.html` retires.
