## What this export will claim, and what it will not

Every line will be generated by rule, and **nothing will be run**. Where the exporter has a rule for a node it emits code from it; where it does not, it refuses and says so. It never guesses — and it never executes your graph, records its behaviour, or compares the generated code against it.

The export is also **one-way**: the code will not sync back, and re-exporting overwrites whatever you changed in it.
