# StoryEngine — exported to Swift by NodeGX

- **Open `StoryEngine.xcodeproj` in Xcode** and press Run, or build without Xcode open:
  `xcodebuild -project StoryEngine.xcodeproj -scheme StoryEngine -destination 'generic/platform=iOS Simulator' build`.
- **Everything you edit is in `Sources/StoryEngineKit/`** — one SwiftUI view per component, `Theme.swift` for the
  design tokens, `Router.swift` for the pages. `swift build` builds it on a Mac with no simulator.
- **`EXPORT-PREFLIGHT.md`** says what did not travel to the phone, by name.
