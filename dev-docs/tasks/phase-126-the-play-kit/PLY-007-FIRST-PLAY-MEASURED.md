# PLY-007 — First play, measured

**Phase:** [126](README.md). **Depends on:** PLY-001, PLY-002, PLY-003.

## What

The claim "faster to first fun play" reaches nodegx.io only after this. An OWN-style round, written down in advance
(the OWN-023 round 3 shape: a pre-registered key, graders who were not in the runs, the null hypothesis kept).

- **Arms.** A: a fresh Claude Code, no kit. B: the same, with `@nodegx/play` (skill, starter, shelf). Same model, same
  brief, same budget cap. Later, optionally, C: a cheaper model with the kit (lane 1's question, asked of games).
- **Briefs.** Three, written as a stranger would: one 3D action game (the Threadspace shape), one sim with a big panel
  (the Gala shape), one small arcade game (Coin Run). Never one of our games by name.
- **Measures.** Wall-clock and cost to the **first picture the person can control** (from the transcript and the
  drive). Defects at first look, counted from screenshots by a grader who did not run it (a wall, a black screen, a
  quarter-canvas, a camera that moves on its own). And Richard's blind rating of the first round, without knowing
  which arm made it.
- **Then one round of changes.** Each arm gets the same three play-test points; count what each delivers.

## Acceptance

- **AC1.** The design file is committed before the first run: briefs, arms, measures, what would refute the claim.
- **AC2.** Both arms run on all three briefs; transcripts, screenshots and costs are kept in this phase folder.
- **AC3.** The result is written in plain words, whichever way it goes, and the site's sentence is taken from it. If
  B does not beat A, the site says nothing about speed.
